# Cleanity Project Information

## Summary
Cleanity is an AI-Powered Cleaning Supply Forecasting Platform designed for B2B applications. The project appears to be in early development stages with a structured frontend component and placeholder directories for backend, AI model, and blockchain integration.

## Structure
- **frontend/**: React-based web application
- **backend/**: Server-side application (directory structure only)
- **ai-model/**: Machine learning components (empty directory)
- **blockchain/**: Blockchain integration components (empty directory)
- **docs/**: Project documentation (empty directory)

## Main Repository Components
- **Frontend**: React application for user interface
